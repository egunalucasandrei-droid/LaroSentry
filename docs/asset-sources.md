# Asset sources

Court visuals in `apps/web/src/court-art.tsx` are original SVG illustrations made for this project. Every use is labeled demo illustration or explicitly described as not a venue photograph. They are not evidence of a real business, actual facility condition or verified availability. No stock photography has been downloaded, and no fabricated customer portraits/testimonials/ratings appear.

Interface icons use Lucide (ISC license). The website uses system Segoe UI/Arial fonts; no external font request is required. Maps use Leaflet and OpenStreetMap standard tiles, loaded only when the visitor chooses map view. Required attribution links remain visible.

Map terms reference: [OpenStreetMap tile usage policy](https://operations.osmfoundation.org/policies/tiles/). This low-volume local demonstration uses ordinary browser caching and no tile prefetch/bulk download. It has no public geocoder integration. Before wider use, configure a suitable provider adapter and capacity plan; the community service is not an unlimited production CDN. Coordinates are approximate fictional demo points and are labeled accordingly.
